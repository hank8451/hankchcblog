## LeetCode 235 - Lowest Common Ancestor of a Binary Search Tree

### 目標
給你一個 Binary Search Tree，並給你兩個節點 p 跟 q，要你找出最低的共同父母 LCP（聽起來好怪），題目有假設樹上沒有重複的節點，以及 p、q 必定存在在樹上。

### 初始想法
寫完236後，嘗試用遞迴的思路去解

### 實作遇到的困難
0.2% 卡頓後順利寫出來，從看題目到寫完大約花 7 分鐘

### AI提供的思路
BST 的特性是，目標比當前節點大 → 往右子樹找，目標比較小 → 往左子樹找，因此在遍歷節點通常不會有回溯的需求，只需要當前節點即可，因此此題用迭代的方式會有更佳的空間複雜度O(h) →O(1)

### 內化後的思路
與 236 相同，一開始在解題時從底向上思考，並以簡單的 Case 為例子、思考邊界條件，並根據子問題的答案組合出最終的答案，遞迴寫出來後，再來找優化的方法。（應該要先寫 235 再寫 236 的）
又或是，被236影響，不然一開始寫的就是迭代的寫法；重點應該要放在236哈哈。

## LeetCode 701 - Insert into a Binary Search Tree

### 目標
給你一個 Binary Search Tree 跟一個整數，把整數插入 BST 中，並維持 BST

### 初始想法
我的想法是從根節點開始想，如果整數小於當前節點，則新增的節點會放在當前節點的左子樹；反之則放在右子樹。

### 實作遇到的困難
沒有，但就是對一開始寫的遞迴沒有信心，雖然也是一次就對。

### AI提供的思路
AI 覺得我的思路、程式碼都很讚，給我更優化的方向就是用迭代，空間複雜度可以從O(h)→ O(1)，原因是 235 一樣。

### 內化後的思路
用遞迴來思考，用迭代來優化
