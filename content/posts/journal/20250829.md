## LeetCode 450 - Delete Node in a BST

### 目標

給一個 Binary Search Tree 跟一個整數 N，刪除 BST 中的整數 N 這個節點。

### 初始想法

我的想法是先找到要刪除的節點，如果找不到，直接回傳原來的BST；如果有找到，接著是找到要替代的節點，可以找他的左子樹最右邊的節點或是右子樹最左邊的節點，找到後把值換掉，並且把他的前一個斷開連結。

### 實作遇到的困難

一開始是用遞迴的方式寫，但是當找到欲刪除的節點時，就卡住了，所以我就想改成用迭代的方式。卡住的原因是不知道怎麼用遞迴的方式把要替換的節點斷開，想說用迭代，就找到後直接 pre = nil

### AI提供的思路

想法沒問題，但是用迭代的方式寫的問題會是，找到欲刪除的節點後找左子樹最右節點或是右子樹最左節點時，會需要維護一個 parent 指針來斷開原來的連結，導致程式碼不簡潔、直觀，但其實也就是把刪除的節點的值替換掉，並把被替換掉的節點刪除。因此用遞迴的方式重建子樹會是比較好的選擇，做法跟我的想法一樣，就是在找到欲刪除節點後，再找到欲替換的節點，替換後再遞迴刪除它。

### 內化後的思路

因為當刪除的節點的左右子樹都有節點時，在刪除過程中必須紀錄它的 parent 節點，刪除後再跟新的子樹將接起來。跟 BST 新增節點不同，新增節點不需要你手動維護 parent 節點，因為你是把節點直接放在葉子節點；因此當樹的操作涉及中間節點時，可以優先考慮用遞迴來解。

- 新增節點: 找到新增的位置後就只是判斷放入當前節點的左子樹跟右子樹而已，因此用迭代沒問題
- 刪除節點: 找到刪除的節點後，還要繼續往下找替換的節點，找到後再回溯回去，因此用遞迴比較好
